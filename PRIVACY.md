# Privacy — Dumb Browser

- Your data stays on your phone. There are no accounts and no server.
- Skills (instruction files) and view templates are fetched only from this
  repository, cached on the phone, and fall back to the last good copy if a
  new file breaks.
- PNRs and trips you add belong only to you. They are stored on-device only
  and are never sent anywhere.
- Permissions are off by default and requested only when a feature needs
  them: notifications (trip-change alerts), location (e.g. nearest station),
  camera (e.g. scanning a ticket). The browser's per-site controls still
  apply to websites.
- Skill pages run isolated from your normal tabs.
